ADMIN NOTES — TOKER TRAV’S PRINTS

SITE PURPOSE
This website is a simple, professional landing site for custom 3D printing services.
The goal is to establish credibility, show examples, explain pricing logic, and push users toward submitting a print request.

FILE STRUCTURE (DO NOT CHANGE)
All files live in ONE folder for GitHub Pages compatibility.

index.html    → Landing / hero page
product.html  → Services & examples
pricing.html  → Pricing overview
request.html  → Customer request form
about.html    → About / credibility
style.css     → ALL site styling
main.js       → Optional JS (currently minimal)

Do not add subfolders unless all paths are updated.

PAGE BACKGROUNDS
Each page uses a body class to control its background image.
Example:
<body class="pricing-page">

If a page loads with no background:
- Check the body class
- Check the image URL
- Hard refresh browser (Ctrl+F5)

NAVIGATION
- Logo always links to index.html
- “Request a Print” is the main call-to-action
- Keep navigation simple; no dropdowns needed

DESIGN SYSTEM
- Dark theme with green/purple accent highlights
- Glass/frosted cards used across services, pricing, and info sections
- Subtle hover effects only (no flashy animations)

If cards lose their glass effect:
- Make sure the glass card CSS is at the bottom of style.css

PRICING STRATEGY (IMPORTANT)
Pricing is intentionally flexible and not locked to exact numbers.
Reason:
- Custom work varies by material, size, print time, and complexity
- Encourages customers to submit a request instead of price shopping
- Prevents underpricing jobs

If asked about pricing:
“Pricing depends on material, size, and print time — submit a request for an accurate quote.”

REQUEST PAGE (MOST IMPORTANT PAGE)
